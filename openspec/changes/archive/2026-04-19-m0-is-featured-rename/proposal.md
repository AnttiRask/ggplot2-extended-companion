## Why

SPEC-v1.2 renames `is_essential` → `is_featured` across the full code, data, and JSON surface area. "Featured in the book" more honestly describes what the flag means (packages covered in the companion book) — "Essential" overpromised. This is a pure mechanical rename: same logical values, same semantics, new name. v1.2 §M0 is a single focused milestone so the grep sweeps in later v1.2 milestones (M1–M3) start from a clean base.

The rename is a **hard break** on the JSON export key. External consumers of `inst/app/www/data/packages.json` will need to update parsers — called out in v1.2 release notes per REQUIREMENTS §3.5.

## What Changes

**Data (source of truth):**
- `data-raw/packages_curated.csv` header row: `is_essential` → `is_featured` (values unchanged)
- `data-raw/migrate_notion.R` literal references

**R code:**
- `R/fct_validation.R`: `validate_is_essential()` → `validate_is_featured()`, dispatch in `validate_curated_csv()`
- `R/fct_filters.R`: `essential_only` parameter → `featured_only`, column reference
- `R/fct_pipeline.R`: `export_json()` JSON key, `merge_package_data()` column refs, file-header docs
- `R/mod_sidebar.R`: input ID `essential_only` → `featured_only`, label "Featured in the Book"
- `R/mod_browse.R`: data column, `essential_badge` var → `featured_badge`, tooltip/aria-label "Featured in the book"
- `R/mod_detail.R`: badge text "⭐ Featured in the book", badge var rename
- `R/app_server.R`: `sidebar_values$essential_only` → `sidebar_values$featured_only`

**Styling:**
- `inst/app/www/styles.css`: `.badge-essential` → `.badge-featured` (same rule body)

**JSON artifact:**
- `inst/app/www/data/packages.json`: regenerated by the next pipeline run with `is_featured` key (no manual edit)

**Tests:**
- `tests/testthat/test-fct_validation.R`: rename function, add missing-column case parallel to `validate_is_archived`
- `tests/testthat/test-fct_filters.R`: `essential_only` argument → `featured_only`
- `tests/testthat/test-fct_pipeline.R`: `export_json()` asserts `is_featured` key
- `tests/testthat/test-fct_json.R`: JSON export key assertions
- `tests/testthat/test-fct_data.R`: fixture references
- `tests/testthat/test-mod_detail.R`: badge label "Featured in the book"

## Capabilities

### Modified Capabilities
- `archived-package-validation`: unchanged, but neighbouring `validate_is_essential` is retired in favour of `validate_is_featured` (same shape).

### New Capabilities
- `featured-package-rename`: the `is_featured` logical column and its enforcement surface (validation, filtering, JSON export, UI labels).

## Impact

**Files modified:** 12 R/source files + 2 data files + 1 CSS file + 6 test files.
**Files created:** 0.
**Files deleted:** 0.

**No new package dependencies.** No behavioural change — same logical values flow through renamed fields.

**Breaking:** JSON export key (`inst/app/www/data/packages.json`). Release notes flag this (called out in SPEC §3.2). The Parquet rewrite is automatic on next pipeline run; the curated CSV rename is a single header-row change (455 rows of values untouched).

**Downstream milestones unblocked:** M1 (layout restructure), M2 (connection stability), M3 (empty-state button & URL filter sync) rely on clean grep hits for `is_essential` being gone.
