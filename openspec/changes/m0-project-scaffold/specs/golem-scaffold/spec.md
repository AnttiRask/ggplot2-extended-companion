## ADDED Requirements

### Requirement: Golem package structure
The project SHALL be a valid R package following golem conventions with DESCRIPTION, NAMESPACE, app.R entry point, and core R files (app_config.R, app_server.R, app_ui.R, run_app.R).

#### Scenario: DESCRIPTION contains required metadata
- **WHEN** DESCRIPTION file is read
- **THEN** it SHALL contain Package name "ggplot2.extended.companion", Title, Version (0.0.0.9000), and all dependencies listed in SPEC section 12 (shiny, bslib, golem, reactable, duckdb, dplyr, arrow, logger, jsonlite)

#### Scenario: app.R entry point exists
- **WHEN** app.R is executed
- **THEN** it SHALL call `golem::run_app()` via `pkgload::load_all()` pattern

#### Scenario: run_app function exists
- **WHEN** `run_app()` is called
- **THEN** it SHALL launch the Shiny app using `golem::with_golem_options()`

#### Scenario: app_server function exists
- **WHEN** `app_server(input, output, session)` is called
- **THEN** it SHALL execute without error (empty server for M0)

#### Scenario: app_config exists
- **WHEN** `app_sys()` is called with a path
- **THEN** it SHALL return the path within the installed package's directory

### Requirement: NAMESPACE auto-generated
The NAMESPACE file SHALL be auto-generated by roxygen2 and SHALL export `run_app`.

#### Scenario: NAMESPACE exports run_app
- **WHEN** NAMESPACE is inspected
- **THEN** it SHALL contain `export(run_app)`
